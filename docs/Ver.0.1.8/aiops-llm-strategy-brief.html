KOMSCO AIOps Agentic Model — 핵심 역할 6종

Model Roles
현재(Rule-based) vs 목표(AI 모델) 비교
🗺️

OS Context Classifier

현재: 키워드 if/elif
목표: 모델 Intent 분류

Linux / Windows / OCP 환경 판단. 현재는 journalctl/windows 키워드에 의존.

🔧

Tool Router

현재: 시나리오별 하드코딩
목표: 모델이 동적 선택

질문에 필요한 tool_plan 자동 구성. event_tool → grep_tool → metric_tool 우선순위 결정.

📋

Evidence Planner

현재: 고정 step 배열
목표: 동적 증거 우선순위

어떤 증적을 어떤 순서로 수집할지 계획. 현재 step은 시나리오마다 정적으로 정의.

🔬

RCA Reasoner

현재: 정규식 파싱
목표: 모델 기반 추론

수집된 증거에서 cause_candidates 도출. 현재는 "원인:" 패턴 정규식 매칭에 의존.

📐

JSON Formatter

현재: 수동 dict 조립
목표: 모델 구조화 출력

Lightspeed에 넘길 RCA Context JSON 생성. 모델이 직접 JSON Schema를 준수한 출력을 생성해야.

🛡️

Safety Guard

현재: 금지어 목록 필터
목표: Safety-tuned 모델

delete/patch/scale 위험 명령 차단. 현재 forbidden_actions 리스트 기반 — 우회 가능성 있음.

⚠️ 6가지 역할 모두 현재 Python 코드(rule-based)로 구현되어 있습니다. 이 레이어가 AI 모델로 교체되는 것이 PDF 요구사항의 핵심입니다. LLM이 배포되기 전까지는 현재 rule-based 구현이 프로덕션을 담당하고, 파인튜닝 완료 후 점진적으로 교체합니다.
