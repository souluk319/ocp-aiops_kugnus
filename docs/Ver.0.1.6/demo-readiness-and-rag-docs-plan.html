목표

복구 가능성재부팅 후에도 짧은 순서로 로컬 시연 환경을 다시 띄운다.

설명 가능성무엇이 로컬이고 무엇이 회사 OCP 연결인지 발표자가 말로 설명할 수 있게 한다.
검증 가능성성공/실패를 화면 느낌이 아니라 report와 verifier로 남긴다.
