3. 아직 안 한 것

  • 회사 OCP에 신규 runtime 설치 완료라고 말하면 안 된다.
  • Software Catalog 등록 완료라고 새로 보고하면 안 된다. 기존 0.1.0 문서에 기록된 카탈로그 준비/등록 맥락과 현재 로컬 시연은 분리해야 한다.
  • Cypress 브라우저 E2E 전체 PASS라고 말하면 안 된다.
  • 실제 default namespace에 과거 재시작 Pod 로그가 항상 있다고 가정하면 안 된다.
  • 실험 무제한이 회사 OCP에서 안전하다고 말하면 안 된다.
