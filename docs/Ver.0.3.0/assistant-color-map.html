AIOps Assistant 색상 맵

대상 커밋은 a3448b8이며, 기준 파일은 komsco-ai-console-plugin/src/components/assistant.css입니다. 이번 1차 변경은 FAB 챗봇의 차가운 slate 느낌을 줄이고, 흰색/검정 계열을 기본 표면으로 정리한 작업입니다.

1. 전역 색상 토큰

컴포넌트가 직접 색을 반복해서 들고 있지 않도록, FAB 챗봇의 기본 색상은 아래 --komsco-* 토큰을 중심으로 맞춥니다.

Ink 950#1A1A1A
Ink 900#222222
Ink 700#3D4148
Ink 600#5F6670
Surface#FFFFFF
Surface 2#F5F5F5
Surface 3#F0F2F5
Line#D8DDE5
Line Soft#EDEDED
Blue 600#2563EB
Blue 700#174EA6
Blue Soft#EFF6FF
Green Soft#F0FDF4
Amber Soft#FFF7ED

2. 요소별 색상 사용

UI 요소 CSS selector 사용 색상 역할
FAB 챗봇 패널 .komsco-ai__panel 배경 #FFFFFF, 테두리 #D8DDE5, 그림자 rgb(12 12 12 / 18%) 전체 창을 깨끗한 흰색 도구 표면으로 고정합니다.
상단 헤더 .komsco-ai__header 배경 #1A1A1A, 글자 #FFFFFF, 하단 라인 #2563EB 운영 콘솔의 중심 제어 영역을 가장 강하게 잡습니다.
상단 컨텍스트 바 .komsco-ai__context-strip 배경 #FAF9F6, 하단선 #EDEDED 헤더 아래 정보를 따뜻한 흰색 계열로 분리합니다.
상태/모드 pill .komsco-ai__context-pill 글자 #5F6670, 배경 #F5F5F5, 테두리 #D8DDE5 상태 정보를 작게 보이되 읽히게 유지합니다.
입력창 영역 .komsco-ai__composer-wrap 배경 rgb(250 249 246 / 96%), 상단선 #EDEDED 본문과 입력부를 부드럽게 구분합니다.
빠른 프롬프트 버튼 .komsco-ai__quick-prompt 글자 #5F6670, 배경 #F5F5F5, 테두리 #D8DDE5 버튼 수가 많아져도 화면을 어지럽히지 않게 합니다.
텍스트 입력 박스 .komsco-ai__input 배경 #FFFFFF, 테두리 #D8DDE5, 그림자 rgb(12 12 12 / 3%) 입력 위치를 분명히 하되 과한 강조를 피합니다.
오른쪽 인사이트 rail .komsco-ai__insight-rail 배경 #F5F5F5 → #FFFFFF, 좌측선 #D8DDE5 전체 화면에서 오른쪽 정보 패널을 자연스럽게 분리합니다.
연결 상태 카드 .komsco-ai__connection-card 배경 #FFFFFF, 테두리 #D8DDE5, 그림자 rgb(12 12 12 / 4%) 상태 카드는 카드처럼 보이되 무겁지 않게 둡니다.

4. 이번 변경에서 의도적으로 유지한 색

성공/주의/위험 같은 의미색은 제품 판단에 직접 연결되므로 1차 색상 정돈에서 크게 바꾸지 않았습니다. 현재는 표면과 테두리의 칙칙한 slate 느낌을 줄이는 데 집중했습니다.
